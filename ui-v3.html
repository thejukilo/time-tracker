Chrome extension

Install Time Tracker

Track a task without leaving your browser, then save it directly to the Time Tracker.

1

Download and open the Extensions page

Download the Time Tracker extension package, then open chrome://extensions in Chrome. Drag the downloaded package onto the Extensions page.

Download extension
2

Enable Developer mode

Turn on Developer mode in the top-right corner of the Extensions page. Chrome may then ask you to confirm the installation.

If Chrome does not accept the package directly, unzip it, select Load unpacked, and choose the extracted time-tracker-extension folder.
3

Track or enter time

Click the Time Tracker icon in Chrome. Choose a department and category, then either start the timer or enter today’s hours manually. Select Save entry to send it to the tracker.
